## Key Architecture Decisions Made in Planning

**1. Ad isolation fix (Plan 04-04)**
`AdService`/`AdLoadState` moved to `lib/core/ads/` so `map_screen.dart` can call `adServiceProvider` without importing `features/ads/`. `lib/features/ads/` files become re-exports. `ads_isolation_test.dart` stays GREEN.

**2. High score handled by MapScreen (Plan 04-04)**
`GameSessionNotifier._highScoreRepository` is null in production (Phase 2 design). Plan 04-04 wires `highScoreRepositoryProvider` directly in `_advanceToNextFlag()` — reads `previousBest` before `completeGame()`, saves new best after.

**3. GoRouter navigation (Plan 04-02)**
Routes: `/` → HomeScreen, `/play/:mode` → MapScreen, `/result` → CompletionScreen.
CompletionScreen receives `session` + `previousBest` via `context.go('/result', extra: {...})`.

**4. Grand Master sequence (Plan 04-03)**
JSON asset `assets/data/grand_master_order.json` (~196 ISO codes, most-to-least recognizable).
`buildGrandMasterSequence()` in `flag_sequence.dart` de-dupes + appends missing codes.
Loaded async in `_initSequence()`.

**5. HUD widget (Plan 04-04)**
`GameHud` is a plain `StatelessWidget` (score/elapsed/matchedCount/totalFlags as params).
MapScreen watches `gameSessionProvider` → rebuilds every second → HUD stays live.

**6. Hint UX (Plans 04-01, 04-03, 04-04)**
`useHint()` in `GameSessionNotifier` decrements `hintsRemaining`.
`FlagTray` shows hint button. On tap: `Matrix4Tween` animates map to 3× on target; `_hintIso` shown as bright yellow-green (`0xFFBBFF44`) for 3s. Exhausted → dialog → Watch Ad → snackbar (stub always fails, Phase 6 wires real ad).

**7. Star rating logic (Plan 04-05)**
- `previousBest == null`: 3 stars, no overlay (first game)
- `score < previousBest`: 3 stars + "New Personal Best!" banner + confetti (~2s overlay)
- `score ≤ ceil(previousBest × 1.20)`: 2 stars
- otherwise: 1 star
