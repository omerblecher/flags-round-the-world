## What Was Fixed This Session

All 3 original bugs from the previous session are resolved, plus 2 new bugs discovered during testing:

### Bug 1 (FIXED): Drag blocked at game start
- **Root cause:** `AnimatedSwitcher` + `SlideTransition` moves the Draggable's hit-test area with the animation. The flag card is unreachable for 300 ms at game start (and after every correct drop).
- **Fix:** Switched to `FadeTransition` — widget stays at laid-out position throughout, Draggable is always hittable.
- **Commit:** `6a8eb6a`

### Bug 2 (FIXED): SM/VA/LI and 26 other tiny nations render as rectangles
- **Root cause:** SVG pipeline stored 4-vertex bounding-box rectangles for 29 nations too small to render accurately.
- **Fix:** Added `CountryData.isDegenerate` (detected by exactly 3 L commands + Z in pathString). `WorldMapPainter` now draws a 5-unit dot marker at the centroid for these countries.
- **Commit:** `6a8eb6a`

### Bug 3 (FIXED): Placed countries don't turn grey (highlights issue)
- **Root cause:** `_matchedIsoCodes.add()` mutated the Set in-place. Both old and new `WorldMapPainter` referenced the same object, so `shouldRepaint` always saw equal sets and never triggered a repaint.
- **Fix:** Replaced `_matchedIsoCodes` with a new Set (`{...old, newIso}`) on each advance. Also fixed `shouldRepaint` to use `setEquals`.
- **Commit:** `6a8eb6a`

### Bug 4 (FIXED): Mauritania not recognised + no hover highlight at low zoom
- **Root cause:** `_kMinBboxDiagonal = 32` was in scene units. At scale 0.2 (zoomed out), 32 scene units = 6 screen pixels — far too small. `hitTest` returned null for any drop not landing precisely inside a tiny path, so hover never highlighted and drops were missed.
- **Fix:** Scale-aware tap target: `minSceneDiag = 40px / currentScale`. Passed `_controller.value.getMaxScaleOnAxis()` to `hitTest()` at both call sites. Works correctly at any zoom level.
- **Commit:** `44ada86`

### Also fixed (same commits):
- WR-05: `_trayCardKey` was `final GlobalKey` — would throw "Multiple widgets used same GlobalKey" during AnimatedSwitcher transition. Now `var`, reassigned on each advance.
- CR-02: `_toSceneFromGlobal` had hard `!` null assertion. Now returns `Offset?` with null guard.
- WR-02: `svc.init()` in main.dart now uses `unawaited()`.
