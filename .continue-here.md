## What Was Fixed This Session (commit 9f1625e)

### Bug 1 (FIXED): Zoom jumps wildly below 1x scale
- **Root cause:** `_zoom()` set matrix entries (0,0) and (1,1) but never (2,2).
  `getMaxScaleOnAxis()` returns 1.0 at any scale below 1x (Z-axis entry stays 1.0).
  Tapping zoom-in from 0.2x caused a wild jump to 1.5x instead of smooth zoom.
  Same bug fed wrong scale to `hitTest()` — tap targets too small when zoomed out.
- **Fix:** `m.setEntry(2, 2, newScale)` in `_zoom()`.

### Bug 2 (FIXED): Map showed only top-left corner on load
- **Root cause:** No initial fit-to-screen.
- **Fix:** `_fitMapToScreen()` via post-frame callback after first data load.

### Bug 3 (FIXED): Andorra, Maldives, Cape Verde, 100+ countries unhittable at low zoom
- **Root cause:** Smallest-bbox-area tiebreaker always picked degenerate countries
  (8x8=64 sq units) — their 222x222 scene-unit expanded bbox swallowed nearby centroids.
- **Fix:** Changed tiebreaker to closest-centroid-distance.

### Bug 4 (FIXED): France centroid in Spain, US in Canada, SA in Namibia
- **Root cause:** Pipeline used area-weighted centroid of merged union, overseas
  territories pulled centroids across borders.
- **Fix:** `representative_point()` of largest polygon. Regenerated world_map_paths.json.

### Bug 5 (FIXED): Target ring invisible at low zoom
- **Fix:** Scale-adaptive ring: radius = (16.0 / viewScale).clamp(6.0, 80.0).
  viewScale passed from MapScreen via controller listener.
