## What Was Fixed This Session (commit 9c9aa62)

### Singapore not recognized (NEW — fixed this session)

- **Root cause**: Malaysia's peninsular SVG path geometrically contains Singapore's
  territory at 1:110m resolution. At zoom ≥ 3×, Singapore's bbox diagonal (11.78 units)
  exceeded `minSceneDiag`, so `_expandedBbox` returned the original 8.33×8.33 rect with
  no expansion. Drops just outside this tiny rect (e.g. 3 units north = ~10px at 3× zoom)
  only found Malaysia as a candidate → Malaysia won.

- **Fix**: `_expandedBbox` in `lib/features/map/hit_detection.dart` now uses
  `max(minSceneDiag, diagonal × 2.0)` as the effective minimum for `isDegenerate`
  countries. Gives a consistent ~one-rect-width padding in each direction at any zoom.
  Centroid tiebreaker correctly prefers Singapore (distance ≈ 0) over Malaysia (≈60 units).

- **Applies to all degenerate micro-states**: Monaco, Vatican, Andorra, San Marino, etc.

### Previously fixed bugs (prior sessions)

1. Zoom jumps wildly below 1× scale — `m.setEntry(2,2,newScale)` in `_zoom()`
2. Map showed only top-left corner on load — `_fitMapToScreen()` post-frame callback
3. Andorra/Maldives/Cape Verde unhittable at low zoom — closest-centroid tiebreaker
4. France/US/SA centroids in wrong countries — `representative_point()` of largest polygon
5. Target ring invisible at low zoom — scale-adaptive ring radius
