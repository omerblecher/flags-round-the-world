**Proxy Audit — 5-point COPPA verification checklist**

This is the Phase 6 mandatory manual verification step. Complete all five points before typing "approved".

**Setup (one-time):**
1. Install mitmproxy (free) from https://mitmproxy.org or Charles Proxy ($50) from charlesproxy.com
2. In Android emulator settings: set HTTP proxy to `127.0.0.1:8080` (mitmproxy default) or `127.0.0.1:8888` (Charles)
3. Install the proxy CA certificate on the emulator (mitmproxy: run `mitmproxy`, browse to `mitm.it` on the emulator device, install cert; Charles: Help -> SSL Proxying -> Install Charles Root Certificate on Android Device)
4. Start proxy with SSL interception enabled for: `*.doubleclick.net`, `*.googlesyndication.com`, `*.unity3d.com`, `*.is.com`, `*.inmobi.com`
5. The `debug-overrides` in `android/app/src/main/res/xml/network_security_config.xml` (added in 06-01) allows the proxy CA cert to be trusted in debug builds — no additional device config needed

**Audit steps:**
1. Run `flutter run` on the emulator (debug mode) with the proxy running
2. Play through a full game session: tap a mode, match several flags, exhaust hints (trigger rewarded ad prompt), complete the game (trigger interstitial on CompletionScreen), background the app and return (trigger App Open)
3. In the proxy, filter requests to these domains and search ALL request bodies/headers/query params for these strings:
   - `gaid` — Google Advertising ID
   - `idfa` — iOS IDFA
   - `advertising_id` — GAID parameter key
   - `android_id` — Android hardware ID
   - `device_id` — generic device identifier
   - `aaid` — alternate GAID label

**Expected results (all must be true for PASS):**
- [ ] Point 1: All advertising ID values in AdMob requests are `00000000-0000-0000-0000-000000000000` (zeroed, indicating child-directed treatment received) — OR the parameter is absent entirely
- [ ] Point 2: Unity Ads requests (unity3d.com) show no non-zero advertising identifiers
- [ ] Point 3: ironSource requests (android-sdk.is.com) show no non-zero advertising identifiers
- [ ] Point 4: InMobi requests (w.inmobi.com) show no non-zero advertising identifiers
- [ ] Point 5: No requests to `firebase.googleapis.com`, `crashlytics.com`, `firebaseinstallations.googleapis.com`, or any Firebase endpoint
- [ ] Verify Unity Ads and ironSource are on the Google Play Families Self-Certified Ads SDK Program list:
      URL: https://support.google.com/googleplay/android-developer/answer/9900633
      If a network is NOT listed: remove it from the AdMob mediation group in AdMob console
      (keep the pubspec package — just don't activate it in the AdMob waterfall)

**Visual verification (bonus, not blocking):**
- Banner ad appears at the bottom of HomeScreen
- Banner ad appears at the bottom of CompletionScreen
- No banner visible during MapScreen gameplay
- Interstitial fires when CompletionScreen first mounts
- App Open fires when returning from background (if not in a game session)
