    Create `scripts/generate_map.py` implementing the full pipeline. Base the implementation on the complete Python pipeline skeleton in RESEARCH.md §Code Examples, but with these required additions and clarifications:

    IMPORTS: `geopandas`, `json`, `math`, `shapely.geometry` (MultiPolygon, Polygon). No other imports needed.

    CONSTANTS:
    - VIEWBOX_WIDTH = 2000.0
    - VIEWBOX_HEIGHT = 1000.0
    - EXCLUDED_ISOS = {'eh', 'ps'}  (Western Sahara and Palestine per D-08)

    COORDINATE FUNCTIONS (must match exactly for Phase 3 compatibility):
    - `lon_to_x(lon)`: `(lon + 180.0) / 360.0 * VIEWBOX_WIDTH` rounded to 2 decimal places
    - `lat_to_y(lat)`: `(90.0 - lat) / 180.0 * VIEWBOX_HEIGHT` rounded to 2 decimal places

    ISO CODE FUNCTION `get_iso_code(row)`:
    - Read `row.get('ISO_A2', '-99')` and strip whitespace
    - If valid 2-char string that is not '-99': return it lowercased
    - If invalid: check NAME field for 'Kosovo' → return 'xk'
    - If invalid: check NAME field for 'Taiwan' → return 'tw' (in case ISO_A2 is also -99 for Taiwan)
    - Otherwise: return None (skip the row)
    - After getting iso: if iso in EXCLUDED_ISOS: return None

    POLYGON TO PATH `polygon_to_path(polygon)`:
    - Extract `list(polygon.exterior.coords)[:-1]` (drop repeated last point)
    - First coordinate: `f"M{lon_to_x(lon)},{lat_to_y(lat)}"`
    - Remaining: `f"L{lon_to_x(lon)},{lat_to_y(lat)}"`
    - Append "Z"
    - Join with " " separator
    - Return None if fewer than 3 coordinates

    BOUNDING BOX: compute from all projected x,y coordinates across all polygons for the ISO group.

    CENTROID: use `geometry.centroid` of the merged/unioned geometry for the ISO group (not per-polygon). Use `union_all()` if merging multiple geometries, or `unary_union` for older geopandas versions. Compute `lon_to_x(centroid.x)` and `lat_to_y(centroid.y)`.

    ANTIMERIDIAN HANDLING: After loading with geopandas, re-project to EPSG:4326 with `gdf.to_crs('EPSG:4326')`. For countries that cross the antimeridian (lon jumping >180°), Natural Earth 110m pre-clips most of them, but Russia in particular may have issues. If a polygon produces a path string where consecutive x-coordinates differ by more than 1500 units (in the 2000-wide viewBox), split it into two sub-polygons at the antimeridian. Log a warning to stderr for any such splits (do not silently discard geometry).

    DATA SOURCE: Download directly in the script using geopandas:
    `gdf = gpd.read_file('https://naciscdn.org/naturalearth/110m/cultural/ne_110m_admin_0_countries.zip')`
    geopandas caches the downloaded file. Alternatively, if the ZIP is already downloaded locally, read from a local path and add an `--input` CLI argument option using `argparse`. Default to the URL if no local path given.

    MERGING: Multiple shapefile rows with the same ISO code (e.g., France overseas territories per D-05) are merged under one entry. Merge by extending the `paths` list and recomputing bounding box and centroid from the union of all geometries.

    OUTPUT: Write to `assets/map/world_map_paths.json` using `json.dump(output, f, separators=(',', ':'))` (compact format to minimize APK size). Print `f"Generated {len(countries)} countries"` to stdout.
