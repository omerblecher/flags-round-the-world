    GREEN cycle — implementation:

    GameSessionNotifier constructor signature:
      GameSessionNotifier({required Ticker ticker, GameStateRepository? gameStateRepository, HighScoreRepository? highScoreRepository})

    Internal state (private fields):
      - int _elapsedSeconds = 0
      - int _countdownTick = 0
      - List<String> _remainingIsoCodes = []

    build() method:
      - Registers ref.onDispose(_ticker.stop)
      - Returns const GameSession(phase: GamePhase.idle, mode: GameMode.learn, score: 0, elapsed: Duration.zero, errorCount: 0, activeIsoCode: null, hintsRemaining: 2)
      - Return type is GameSession (not Future<GameSession>) → provider initializes as AsyncData immediately

    startGame(GameMode mode):
      - Resets _elapsedSeconds = 0, _countdownTick = 0
      - Sets state = AsyncData(current.copyWith(phase: GamePhase.countdown, mode: mode, score: 0, elapsed: Duration.zero, errorCount: 0, activeIsoCode: null, hintsRemaining: 2))
      - Calls _ticker.start(_onTick)

    _onTick() private method:
      - If state is AsyncData and phase == countdown: _countdownTick++; if _countdownTick >= 3 → state = AsyncData(copyWith(phase: GamePhase.playing))
      - If phase == playing: _elapsedSeconds++; compute score = (_elapsedSeconds ~/ 10) + (current.errorCount * 5); state = AsyncData(copyWith(score: score, elapsed: Duration(seconds: _elapsedSeconds)))

    pauseGame():
      - _ticker.stop()
      - state = AsyncData(current.copyWith(phase: GamePhase.paused))

    resumeGame():
      - state = AsyncData(current.copyWith(phase: GamePhase.playing))
      - _ticker.start(_onTick)

    recordDrop(String isoCode, {required bool isCorrect}):
      - If isCorrect: call _gameStateRepository?.saveSession(current); update state (no errorCount change)
      - If not isCorrect: increment errorCount, recompute score, update state

    completeGame():
      - _ticker.stop()
      - state = AsyncData(current.copyWith(phase: GamePhase.completed))
      - If _highScoreRepository != null: call saveBestScore(current.mode, current.score)

    countdownSecondsRemaining getter (public, on notifier not model — per RESEARCH.md Open Question 1):
      int get countdownSecondsRemaining => 3 - _countdownTick;

    Import constraint (CRITICAL):
      - Import only: dart:async, flutter_riverpod, and the three lib/features/game/ + lib/core/ files
      - NO import of features/ads/ — enforced by ads_isolation_test.dart

    Provider declaration at top level (per D-07):
